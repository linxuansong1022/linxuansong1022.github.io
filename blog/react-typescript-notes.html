A small playground for reading React code. Each section pairs the code shape with a live preview, so you can see what state, props, conditions, lists, and context actually change on the page.

Read this page from left to right: code on the left, live behavior on the right. The goal is not to memorize everything, but to recognize the pattern when you see it in a real codebase.

1. useState

state changes UI 
const [count, setCount] = useState(0)

const increment = () => {
  setCount(prev => prev + 1)
}

return (
  <button onClick={increment}>
    Count: {count}
  </button>
)

The value is count. The only safe way to update it is setCount.

pass data in 
function Button({ variant, children }) {
  return (
    <button className={`btn ${variant}`}>
      {children}
    </button>
  )
}

<Button variant="primary">

4. List Rendering

array to rows 
{todos.map(todo => (
  <div
    key={todo.id}
    onClick={() => toggleTodo(todo.id)}
  >
    {todo.completed ? 'Done' : 'Todo'}
    {todo.text}
  </div>
))}

map turns each item into UI. key helps React track each row.

5. Context

shared data 
const ThemeContext = createContext()

<ThemeContext.Provider value={{ theme, toggleTheme }}>
  {children}
</ThemeContext.Provider>

const { theme, toggleTheme } = useTheme()

Context is a shared box. Provider puts data in; useContext takes it out.

How to read React code

  • state is data that can change.
  • functions are actions triggered by clicks, typing, or submit.
  • return JSX is what appears on the page.
  • props are inputs passed into a component.
  • map usually means a list is being rendered.
  • context means shared data without passing props through every layer.
